# Primeira publicação

Objetivo confirmado: open source e destaque no portfólio. O bootstrap não publica repositório, instalador ou serviço.

Antes da primeira pública: nome/marca e licença escolhidos; instalação Windows externa reproduzindo os fluxos; configuração de serviços/chaves documentada; evidências, demo e vídeo com dados de teste; funcionalidades anunciadas correspondendo ao que passou.

Grafo, integração de estudo/IA e execução/Git de projetos continuam previstos para a primeira pública. GAM-01/02 já entregam jogo e Explorer/editor locais; são incrementos antecipados, sem aprovar distribuição pública. Se o prazo ultrapassar a janela inicial, preserve essas frentes e revise a previsão pelos checkpoints.

Prova externa do editor assistido, hospedagem, detalhes da distribuição/assinatura e demais escolhas ainda pendentes devem aparecer em ADR/ticket quando resolvidas. Não anuncie “open source lançado” apenas por criar um repositório sem completar a decisão de licença.
